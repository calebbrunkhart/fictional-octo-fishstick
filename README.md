# Caleb Brunkhart — Academic Website (Astro + TypeScript + Tailwind + MDX)

This is a static, **backend-free** personal academic website scaffold built with Astro, TypeScript, Tailwind CSS, and MDX. It is suitable for direct deployment on **GitHub Pages**.

## Features
- Static site (no backend)
- Dark / Light theme with toggle
- MDX blog support
- All content is local: `/data/*.json` and `src/pages/blog/*.mdx`
- Pages included: Home, About/Timeline, Research, Teaching, Publications, Blog, Contact
- Sample content (replace as you like)

## Quick start

1. Install:
bash
npm install
2. Develop (local):
npm run dev
open http://localhost:3000
3. Build (production)
npm run build
